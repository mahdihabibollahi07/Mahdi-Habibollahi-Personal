# Mahdi Habibollahi Personal Website — Phase 2

Static portfolio built with HTML, CSS and Vanilla JavaScript.

## Included in Phase 2
- Dedicated project pages
- Dedicated blog pages
- Dark/Light theme
- Responsive navigation
- Project filtering
- Local AI Corner
- Copy-email interaction
- SEO metadata / Open Graph
- JSON-LD
- robots.txt
- sitemap.xml
- Web App Manifest
- GitHub Pages friendly architecture

## Run locally
Open `index.html` directly, or serve the folder with any static HTTP server.

## GitHub Pages
Push the project to a GitHub repository and enable GitHub Pages from the repository's Pages settings.

> Before publishing, replace placeholder contact/social links and verify the canonical GitHub Pages URL.
